# Flutter Form Builder

A web-based visual editor for the `flutter_form_generator` ecosystem. This tool allows developers and non-technical users to design forms visually and export the corresponding JSON configuration.

## ✨ Features

-   **Visual Canvas**: Drag-and-drop interface for arranging form fields.
-   **Row-Based Layout**: Organize fields into responsive rows.
-   **Field Configuration**:
    -   Edit labels, placeholders, and default values.
    -   Add validation rules (Regex, required, etc.).
    -   Set up conditional dependencies (`enabledIf`).
-   **JSON Management**:
    -   **Import**: Paste existing JSON to edit forms.
    -   **Export**: Generate JSON for use with the `flutter_form_generator` plugin.
    -   **Preview**: See a live preview of the form as you build it.

## 🚀 Getting Started

1.  Ensure you have Flutter installed.
2.  Run the app in Chrome:

```bash
flutter run -d chrome
```

## 🔗 Integration

The JSON generated by this tool is designed to be consumed by the `flutter_form_generator` plugin. Copy the output from the "View JSON" dialog and pass it to the `FormGenerator` widget in your Flutter app.
